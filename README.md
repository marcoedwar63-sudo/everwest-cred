# EVER WEST — CRED Developments

Static production build reconstructed from the published site HAR for GitHub hosting.

## Conversion links
- Register Your Interest → Google Form
- Book a Viewing → Google Calendar Appointment Schedule
- WhatsApp → direct WhatsApp chat

No Supabase, Resend, Google API, OAuth, or custom booking backend is required.

## Deploy on GitHub Pages
Upload all files to the repository root, then enable **Settings → Pages → Deploy from a branch → main / root**.
